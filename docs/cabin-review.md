# Local Cabin Fever review

Run `./dev.sh`, then open its printed local URL with `?level=cabin&review=cabin` appended. For example: `http://127.0.0.1:5173/?level=cabin&review=cabin` (use the port printed by the script). This opens Level 9 without playing earlier levels.

The LOCAL REVIEW notice confirms the bypass. It is limited to Vite development builds on loopback addresses; release builds retain the Carnival-completion requirement. Review mode uses session-only level progression and does not write fabricated completion flags. Scores and audio/control preferences remain local to the local-server browser origin.

Press Start Game, cross the woods and lake, use Action at the far-shore cooler, then return left and use Action at the cabin. Water returns to the last dry-land checkpoint and preserves acquired beer with a condition penalty. Restart resets the mission and route.
