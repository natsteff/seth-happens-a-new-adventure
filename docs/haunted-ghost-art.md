# Original Haunted House ghosts

`public/assets/haunted/ghosts-v1.png` is a new transparent 2×2 atlas created with the built-in image-generation tool for this game. One shared texture supplies the wraith, skull spirit, shrieking specter and crowned attic pursuer. No existing character likeness or sprite was supplied or reused. Regular Allison remains separate. Existing collision sizes, phase timing and escape mechanics are unchanged; decorative silhouettes extend beyond collision boxes.

Prompt: Create four original creepy supernatural ghosts, each isolated inside one quadrant of a regular transparent 2×2 atlas: gaunt hooded bone-mask wraith with long claws; hollow-eyed skull spirit with cyan smoke spine; hunched violet specter with branchlike arms and a screaming face; larger crowned landlord phantom with multiple claws and torn robes. Polished painterly cartoon realism, readable small silhouettes, cyan/green/lavender edges. No recognizable people, women/Allison, clowns, concert people, gore, text, scenery or painted checkerboard. Complete bodies, transparent margins, no overlap.

The generated master and prior supplied originals are retained locally. The atlas also supplies the Credits/Jukebox ghost dancers and is lazy-loaded there. No full-scene or per-ghost duplicate bitmap allocation is required.
